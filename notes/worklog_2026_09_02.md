# Worklog — 2026-09-02

## Goal
Stabilize the combined-model evaluation with repeated k-fold CV and investigate whether the malate floor correction affects metabolite classification.

---

## 1. Experimental design decisions

### Cohort
- **139 organoids**: series_idor, BA1 + BA2, including 6 stitched organoids (2 NAcc, 4 Acc).  
  Previous runs used 132 (canonical Splits, no stitched).
- **25 Not-Acceptable / 114 Acceptable**, 11 time points Dy03–Dy30.

### Cross-validation
- **10 repeats × 4-fold stratified CV** (previously: 1 × 4-fold or 1 × 5-fold).
- Seed for repeat *r*: `SEED + r × 1000` → genuinely independent fold assignments.
- Same fold partition shared across all modalities within a repeat → valid late fusion.
- Metric reported: mean ± SD of per-repeat OOF balanced accuracy.

### Why repeated k-fold?
With 25 NAcc / 139 total, a single 4-fold run has high variance (each fold has 6–7 NAcc in the test set). 10 repeats halves the std vs. a single run without requiring more GPU time.

### 3 metabolite variants (trained independently each fold)
| Key | Description |
|---|---|
| `met_nan` | Values < −500 µM (CONCENTRATION_FLOOR) replaced with NaN — original approach |
| `met_raw` | Raw concentration; no floor correction |
| `met_no_malate` | MalateGlo feature excluded entirely |

**Result**: `met_nan` ≈ `met_raw` ≈ `met_no_malate` to 3 decimal places at almost every day. The floor correction makes no practical difference on this dataset.

## 2. Code changes

### `analysis/paper_2026_04/metabolites_train.py`
- Added `malate_mode` parameter to `_features_for_day_all` (no-splits path only):
  - `"nan"` (default): existing floor behavior
  - `"raw"`: skip floor, use raw values
  - `"drop"`: exclude MalateGlo from `active_mets`

### `analysis/paper_2026_04/combined_kfold.py`
- Added `--n-repeats` argument (default 1; runs use 10).
- `run_day` restructured:
  - Pre-computes 3 met feature arrays once per day (outside repeat loop).
  - Outer loop over `n_repeats`; each repeat uses seed `SEED + rep × 1000`.
  - Trains 3 LightGBM met models + morph + image per fold.
  - Result keys: `met_nan`, `met_raw`, `met_no_malate`, `morph`, `img`,  
    plus all pairwise/3-way fusions (`met_nan+morph_mean_prob`, `met_nan+morph+img_mean_prob`, etc.).
  - Stores per-repeat:
    - `repeat_balanced_accuracies` — list of 10 OOF BAs
    - `repeat_confusion_matrices` — list of 10 `[[TN,FP],[FN,TP]]` (single mods only)
    - `repeat_details` — full record per repeat: `seed`, `org_ids`, `true_labels`,  
      `fold_assignments` (which fold 0–3 each organoid was in), `oof_probs`, `oof_preds`
